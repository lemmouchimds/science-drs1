# مراجعة علوم الطبيعة والحياة — السنة الأولى ثانوي

تطبيق ويب تفاعلي لمراجعة درسين:

1. **آليات النمو والتجديد الخلوي والانقسام**
2. **مصدر المادة العضوية ودوران النسغ**

## المميزات
- 🧊 **شرح تفاعلي ثلاثي الأبعاد** (Three.js): مناطق النمو، مراحل الانقسام الخيطي المتساوي، بنية الصبغي، دوران النسغ، الأوعية الناقلة
- 📄 ملخص لكل درس
- 🃏 بطاقات مراجعة مع حفظ التقدم
- ✅ اختبارات اختيار من متعدد + اختبار شامل
- 🔬 لعبة ترتيب مراحل الانقسام و 🗂️ لعبة التصنيف

صفحة واحدة (`index.html`) بدون أي خطوة بناء.
